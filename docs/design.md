# TrickTimer 设计

2026-10-07。用户已确认玩法、浅色界面，并授权文档完成后直接实现和公开部署。

## 体验
打开即是普通计时器。浅色背景、深色等宽数字、蓝色主按钮、细刻度圆环。
秒表 / 倒计时切换；秒表可调整或关闭公开挑战目标，倒计时可设置时长。
手机优先，桌面居中；按钮按压、圆环进度、切换与底部面板有克制的动画，尊重减少动态效果偏好。
长按标题连续 3 秒进入导演设置；松开、取消、移出即取消。支持键盘持续按住空格或 Enter。

## 规则
- 挑战必中、固定暂停结果作用于秒表；变速倒计时作用于倒计时。
- 设置可下一轮、指定第 N 轮或每轮生效。指定轮次从保存之后计数。
- 开始后第一次暂停或倒计时自然完成，算完成一轮；继续再暂停不重复计数。
- 重置清空时间，保留待生效设置；放弃尚未暂停的一轮不计数。
- 单次规则生效后自动清除；每轮规则持续到手动关闭或刷新。
- 秒表整蛊生效轮次：目标为整数秒时，从上一整数秒开始；目标有小数时，从该整数秒开始。将这最后一段平滑延长 500 ms，小数持续前进、不倒跳，圆环跟随显示。到达目标后按正常速度继续，保持 500 ms 的偏移，不突然追赶。
- 固定结果严格显示预设值，允许从显示计时跳变。
- 变速倒计时按显示时长 / 实际时长匀速推进，暂停期间不推进。
- 设置仅存在内存，不写入 localStorage、URL 或云端。刷新恢复正常。
- 保存设置会清空本次计时、重新计数，并切换到适用工具；面板明确告知。
- 时间必须有限且大于零，最大 99 分 59.99 秒；轮次为 1–999 整数。

## 实现与公开部署
原生 HTML / CSS / ES modules，无运行时依赖，无外部字体或追踪。
计时以单调时钟计算，不依赖 interval 累加。动画帧只负责显示，后台返回校正。
语义按钮、焦点恢复、对话框、输入校验、safe-area、触控大按钮。
GitHub Pages 通过 Actions 部署；README 包含访问、正常使用、隐藏入口、规则、开发与隐私说明。
