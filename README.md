# TrickTimer

一个打开即用的在线计时器，也是一部藏在普通秒表里的整蛊工具。

**[打开计时器 →](https://seanwang456.github.io/TrickTimer/)**

原生 HTML、CSS、JavaScript 编写。无运行时依赖，无账号，无广告。适配手机和桌面，支持减少动态效果的系统设置。

## 正常使用

- **秒表**：点击开始、暂停、继续；重置开始新一轮。
- **挑战目标**：点击数字下方的目标按钮，设置例如 `8.88` 或 `10` 秒。也可以关闭目标，作为普通秒表使用。
- **倒计时**：切换倒计时，点击时长按钮设置秒数；支持小数。
- **提示音**：点击右上角扬声器开启，时间到时播放短提示音。默认关闭。

## 隐藏的导演模式

**持续长按顶部「计时器」标题 3 秒**，进入导演设置。电脑可以用鼠标长按，也可以将焦点放到标题上，持续按住空格或 Enter 3 秒。提前松开或移开会取消。

| 玩法 | 设置 | 效果 |
| --- | --- | --- |
| 挑战必中 | 目标时间，例如 8.88 秒 | 暂停时精确显示目标，与实际经过时间无关 |
| 变速倒计时 | 显示时长与实际时长，例如 180 秒 / 300 秒 | 屏幕上的 3 分钟，实际用 5 分钟走完 |
| 固定结果 | 暂停结果，例如 3 秒 | 暂停秒表时显示指定时间 |

秒表整蛊在接近预设结果时，会让最后一段小数位多走约 **0.5 秒**：`3.00` 在 `2.xx` 多停留半秒，`3.25` 在 `3.00–3.24` 多停留半秒。数字和圆环平滑推进，不反复倒跳；随后恢复正常速度，暂停仍显示预设结果。只影响整蛊生效的轮次。

### 几个人轮流玩的例子

1. 长按标题进入设置，选择「挑战必中」。
2. 目标时间输入 `8.88`，生效方式选择「指定轮次」，轮次输入 `3`。
3. 保存并返回，交给第一位挑战者。
4. 每位挑战者开始、暂停查看结果，点击重置后交给下一位。
5. 第三轮会显示 `08.88`，然后自动恢复普通计时。

### 轮次与恢复规则

- 从**保存设置后**开始计数，保存同时清空当前计时。
- 开始后的第一次暂停，或倒计时自然完成，算一轮。
- 继续再暂停不会重复计数。尚未暂停就重置，视为放弃，不占轮次。
- 重置只清空时间，保留尚未生效的设置。
- 「下一轮」「指定轮次」只生效一次；「每一轮」持续生效。
- 在导演面板可查看轮次、关闭整蛊并重新计时。
- **刷新或关闭网页，全部秘密设置清除。** 每次重新打开都是正常计时器。
- 挑战必中 / 固定结果用于秒表；变速用于倒计时。切换到其他工具不会消耗等待生效的轮次。

## 范围与使用说明

时间范围为 `0.01`–`5999.99` 秒（99 分 59.99 秒），轮次范围为 `1`–`999`。
计时根据单调时钟计算，界面使用动画帧刷新，暂停期间不推进。手机锁屏或浏览器进入后台时，显示和提示音可能被系统延后；回到网页后按经过时间更新。

整蛊设置是界面隐藏功能，源码公开，不是密码保护。适合朋友间的轻松娱乐；计时结果不用于正式竞赛或需要准确计时的任务。

## 隐私

应用不使用 Cookie、localStorage、分析脚本、外部字体或第三方 API。设置只保留在当前页面内存中，不发送到服务器；别人打开同一链接不会收到你的设置。站点由 GitHub Pages 托管，访问受其服务政策约束。

## 本地开发

需要 Python 3 启动静态服务器；测试需要 Node.js 22 或更新版本。不需要安装 npm 依赖。

```sh
git clone https://github.com/seanwang456/TrickTimer.git
cd TrickTimer
npm run dev
```

打开 `http://localhost:4173`。ES modules 需要通过 HTTP 访问，请勿直接双击 HTML。

```sh
npm test
```

测试覆盖正常计时、暂停恢复、轮次、单次 / 重复规则、变速计时、非法输入与时间格式。

## 部署

`main` 分支更新后，GitHub Actions 自动运行测试，并只上传网站需要的 5 个文件到 GitHub Pages。
仓库 Settings → Pages → Source 应设置为 **GitHub Actions**。也可手动运行「Deploy GitHub Pages」工作流。

网站采用相对资源路径，适配 GitHub Pages 的仓库子路径，也可部署在任意静态托管服务。
